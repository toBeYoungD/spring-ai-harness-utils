- 触发来源：用户需求——「用新前端根据工程规则覆写旧内容」，并明确「后续将前后台关联起来」（后端对接是后续任务，本次纯前端 + mock 数据）。

  2. **antd**：全工程降级到 4.7.0；既有 v5 组件迁回 v4 API。
  3. **主题**：新组件保留原型亮色（CSS 作用域隔离），既有组件不动，统一留待后续讨论。
  4. **后端对接**：本次不做，mock 数据，留待后续。

## 二、现状分析

- **正式工程**：React18 + Vite5 + antd v5（暗色玻璃拟态）。既有 `FileExplorer` / `McpDebugger` 等组件使用 v5 API：`Tabs items`、`Modal/Drawer open`、`Breadcrumb items`、`ConfigProvider theme={{ algorithm, token }}`。
- **既有 `index.css` 含全局 `!important` 暗色覆盖**（`.ant-table-thead > tr > th`、`.ant-modal-content`、`.ant-drawer-content` 等），作用于整个 document。这是本次最大冲突点：亮色控制台的表格会被全局暗色覆盖压成「白底白字」不可见；且 `Modal`/`Drawer` portal 到 `document.body` 外，包在 `.console-light` 内的作用域变量够不着弹窗内部。
- **原型**：单文件 HTML，Babel CDN 即时编译，antd 4.7（v4 API），亮色主题内联 `<style>`，自带 navbar（移植时去掉，导航由 `App` 统一拥有）。原型本就是 v4 写法（`Tabs.TabPane`、`visible`、`bodyStyle`、`tipFormatter`），移植无需 API 改动。
- 关键定位：`spring-ai-harness-server-frontend/package.json`、`src/App.js`、`src/styles/index.css`、`.claude/preview/index.html`、`.claude/preview/audit-preview.html`。

## 三、方案设计

分四块，核心是「降级 + 移植 + 作用域隔离」。

### 1. antd 全工程降级 v5 → 4.7

既有组件 v5 API 迁回 v4：

| v5（既有） | v4（迁回后） |
|---|---|
| `<Tabs items={tabItems} />` | `<Tabs>{tabItems.map(t => <Tabs.TabPane key={t.key} tab={t.label}>{t.children}</Tabs.TabPane>)}</Tabs>` |
| `<Modal open={v} />` / `<Drawer open={v} />` | `visible={v}` |
| `<Breadcrumb items={items} />` | `<Breadcrumb>{items.map((it,i) => <Breadcrumb.Item key={i}>{it.title}</Breadcrumb.Item>)}</Breadcrumb>` |
| `<ConfigProvider theme={{ algorithm, token }} />` | `<ConfigProvider>`（去 theme，v4 无 algorithm；暗色继续靠 `index.css` CSS 变量 + `data-theme` 属性） |

**取舍**：antd 4.7 发布于 2020-11，早于 React 18 官方支持（4.21+ 才正式支持）。4.7 + React 18 运行时会有 `defaultProps`/`findDOMNode`/`ReactDOM.render` legacy/`Space wrap` 等**非阻断**警告；回退方案为 antd 4.24.x（最新 v4，支持 React 18，API 仍为 v4）。本次按用户决策锁定 4.7.0，回退点记入依赖敏感点。

### 2. 新组件移植（QuotaConsole / AuditConsole）

CDN Babel → Vite ESM 的通用动作：

- `const { Button, ... } = antd` → `import { Button, ... } from 'antd'`
- `window.icons.X` → `import { XOutlined } from '@ant-design/icons'`
- `ReactDOM.render(...)` → `export default function QuotaConsole() { ... }`
- 去掉原型内置 navbar（导航由 `App` 统一拥有）
- 去掉 `I = Cmp => Cmp ? <Cmp/> : null` 防御包装，图标直接 `<XOutlined />`
- 根节点包 `<div className="console-light">`；mock 数据保留内联数组 + `// TODO: 后端就绪后改用 services/api.js`

### 3. CSS 作用域隔离（关键，解决二节冲突点）

策略有三层，对应「变量 / 自定义类 / antd 覆盖」三类规则：

- **CSS 变量**挂在 `.console-light, .console-modal, .console-drawer` 三处选择器列表（页面根 + 两个弹窗 portal 根）。变量名（`--bg`/`--text`/`--primary`…）与 `index.css` 的 `--bg-primary` 等无冲突，不污染全局 `:root`。弹窗 portal 到 body 外，靠 `className="console-modal"`/`"console-drawer"` 落到 `.ant-modal`/`.ant-drawer` 根上，变量由此级联进弹窗内部。
- **自定义类**（`.stat-card`/`.status-pill`/`.cat-tag`/`.json-block`/`.section-label`…）保持全局：命名与 `index.css` 不撞，且能在 portal 弹窗内命中，无需重复作用域。
- **antd 表格/分页覆盖**一律加 `.console-light` 前缀 + `!important`，用高特异性压过 `index.css` 的全局暗色 `!important` 覆盖，避免亮色表格被压成不可见、也避免污染既有暗色组件。
- **弹窗容器**（`.ant-modal-content`/`.ant-drawer-content`）由 `.console-modal`/`.console-drawer` + `!important` 覆盖回亮色。

### 4. App 导航

`App.js` 导入 `QuotaConsole`/`AuditConsole` + `console-light.css`；`activeTab` 新增 `'quota'`/`'audit'`，nav 新增两 Button；Content 渲染改为 `renderContent()` switch（files/mcp/quota/audit）；`ConfigProvider` 去 v5 theme。既有暗色导航栏 + 主题切换不动。

## 五、依赖敏感点

- **antd 4.7.0 全工程降级（自 v5）**：公司内若使用更新版本 antd，需同步降级或评估 v4 API 兼容；既有 v5 组件须按改动清单迁回 v4 API。`npm run build` 可暴露 v5-only 组件残留（Segmented/Tour/QRCode/Watermark/FloatButton 等）。
- **React 18 + antd 4.7 兼容风险**：4.7 早于 React 18 官方支持（4.21+），运行时有 `defaultProps`/`findDOMNode`/`ReactDOM.render` legacy/`Space wrap` 等**非阻断**警告，应用可正常渲染与交互。若公司内要求零警告或出现运行异常，**回退 antd 4.24.x**（最新 v4，支持 React 18，API 仍为 v4；仅 `Tabs`/`Modal` 等少量 API 差异需核对）。
- **moment ^2.29.4**：antd v4 peer dep，原型同版本。公司内若已采用 dayjs 体系，v4 可配 dayjs 替代 moment，需同步改 DatePicker 等本地化与 antd moment 调用。
- **Vite 5 + React 18**：无特殊敏感点，构建配置未改。
- **主题待定**：新组件亮色 CSS 作用域到 `.console-light`/`.console-modal`/`.console-drawer`，与既有暗色 `index.css` 并存；主题统一（亮/暗全局化）留待后续讨论，本次不触碰既有暗色组件样式。
- **后端待对接**：全 mock 数据；后续加 `services/api.js` 方法（`listQuotas`/`setQuota`/`recalc`/`listBehaviorLogs`/`listOperationLogs`/导出）替换 mock。
