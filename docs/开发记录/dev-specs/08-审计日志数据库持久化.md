## 一、背景

- 现状（dev-spec 03 落地）：`BehaviorAuditStore` / `AdminAuditStore` 两个接口 + `DefaultBehaviorAuditStore`（内存 `ConcurrentLinkedQueue`，异步 `CompletableFuture`）/ `DefaultAdminAuditStore`（内存同步）。进程重启即丢，多节点不共享。
- 原设计意图（`docs/开发记录/开发方案/phase2-日志审计开发方案.md`）："`BehaviorAuditStore` 默认本地文件按天分区，可替换为 DB/ES"、"异步队列 + 批量落盘，绝不中断工具调用"。接口早已预留 DB 替换点。
- 本次：接 DB。**只换存储层**，切面（`AuditAspect`）、Controller（`AuditController`）、记录模型（`BehaviorAuditRecord`/`AdminAuditRecord`）、查询模型（`AuditQuery`）零改动。
- 与 dev-spec 07（权限 DB 存储）同一思路：外部仓库不落 DB 代码，本文档即参考实现，公司内按敏感点适配。

## 二、表结构参考（按假设字段名）

> 字段名/类型按惯例假设。**公司内已建的表若字段名不同，调整 Repository 的 SQL 与 `RowMapper` 即可**，接口与切面逻辑不变。

### 表 1：`audit_behavior`（智能体行为日志，每次 MCP 工具调用一条）

```sql
CREATE TABLE audit_behavior (
    trace_id      VARCHAR(64)  NOT NULL,           -- 主键
    ts            BIGINT       NOT NULL,           -- epoch millis（可移植，跨库排序/范围一致）
    system        VARCHAR(64)  NOT NULL,
    agent         VARCHAR(64)  NOT NULL,
    user          VARCHAR(64)  NOT NULL,
    tool_name     VARCHAR(128) NOT NULL,
    tool_category VARCHAR(32)  NOT NULL,           -- file / skill / relay / unknown
    status        VARCHAR(32)  NOT NULL,           -- SUCCESS / FAIL / PERMISSION_DENIED
    duration_ms   BIGINT       NOT NULL,
    error_code    VARCHAR(512),                    -- 失败时 = SimpleClassName: msg
    snapshot_id   VARCHAR(64),
    workspace_key VARCHAR(256) NOT NULL,           -- {system}-{agent}-{user}，identity 过滤用
    oss_prefix    VARCHAR(256),
    args          TEXT,                             -- 入参 JSON 串原样存
    result        TEXT,                             -- 返回值（截断后）原样存
    PRIMARY KEY (trace_id),
    INDEX idx_ts (ts),
    INDEX idx_ws (workspace_key),
    INDEX idx_status (status)
);
```

### 表 2：`audit_operation`（管理员操作日志，配置变更 / 跨空间操作）

```sql
CREATE TABLE audit_operation (
    trace_id        VARCHAR(64)  NOT NULL,
    ts              BIGINT       NOT NULL,
    admin_token_hash VARCHAR(32) NOT NULL,          -- sha256(token) 前 12 位
    admin_action    VARCHAR(64)  NOT NULL,          -- SET_QUOTA / SET_TOOL_PERMISSION / CROSS_WORKSPACE_COPY / REWIND ...
    target_identity VARCHAR(256),                   -- 被操作工作区 / 目标
    target_resource VARCHAR(256),
    result          VARCHAR(32)  NOT NULL,          -- SUCCESS / FAIL
    client_ip       VARCHAR(64),
    summary         VARCHAR(512),
    before_json     TEXT,                            -- 变更前 JSON
    after_json      TEXT,                            -- 变更后 JSON
    PRIMARY KEY (trace_id),
    INDEX idx_ts (ts),
    INDEX idx_admin (admin_token_hash),
    INDEX idx_action (admin_action)
);
```

### 类型取舍（可移植性）

- **时间一律 `BIGINT` epoch millis**：绕开各库 `TIMESTAMP` 时区/精度差异；`Instant ↔ long` 在映射层转。
- **JSON 串（`args/result/before_json/after_json`）存 `TEXT`/`CLOB` 原样字符串**：不用原生 JSON 列（PG `jsonb`/MySQL `json`/Oracle `NCLOB`/SQLServer `nvarchar` 差异大），记录里已是 JSON 字符串，存文本即可，查询也不需要在 DB 侧解析。
- `trace_id` 作主键；`ts`、`workspace_key`、`status`、`admin_token_hash`、`admin_action` 建索引（均为查询/过滤高频字段）。
- **按天分区**：单表 + `ts` 索引为参考实现；若公司内库支持分区（PG 分区表 / Oracle 分区），按天分区可让 retention 用 `DROP PARTITION` 更高效（见依赖敏感点）。

## 五、AuditDialect（方言抽象，最小 seam）

仅抽象分页片段与参数顺序，新库加一个枚举值即可：

```java
package io.github.springai.harness.audit.persistence;

/** 审计查询分页方言。新库支持加一个枚举值即可，Repository 其余 SQL 跨库通用。 */
public enum AuditDialect {

    /** MySQL / PostgreSQL / H2 / 达梦 等：LIMIT ? OFFSET ?，参数顺序 [size, offset] */
    DEFAULT {
        @Override public String pagination() { return "LIMIT ? OFFSET ?"; }
        @Override public Object[] args(int page, int size) { return new Object[]{size, page * size}; }
    },
    /** Oracle 12c+：OFFSET ? ROWS FETCH NEXT ? ROWS ONLY，参数顺序 [offset, size] */
    ORACLE {
        @Override public String pagination() { return "OFFSET ? ROWS FETCH NEXT ? ROWS ONLY"; }
        @Override public Object[] args(int page, int size) { return new Object[]{page * size, size}; }
    },
    /** SQL Server：OFFSET ? ROWS FETCH NEXT ? ROWS ONLY（2012+），参数顺序 [offset, size] */
    SQLSERVER {
        @Override public String pagination() { return "OFFSET ? ROWS FETCH NEXT ? ROWS ONLY"; }
        @Override public Object[] args(int page, int size) { return new Object[]{page * size, size}; }
    };

    public abstract String pagination();
    public abstract Object[] args(int page, int size);

    public static AuditDialect from(String name) {
        if (name == null) return DEFAULT;
        try { return AuditDialect.valueOf(name.toUpperCase()); }
        catch (IllegalArgumentException e) { return DEFAULT; }
    }
}
```

### BehaviorAuditRepository

```java
package io.github.springai.harness.audit.persistence;

import io.github.springai.harness.audit.model.AuditQuery;
import io.github.springai.harness.audit.model.BehaviorAuditRecord;
import lombok.RequiredArgsConstructor;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;

import java.time.Instant;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * 行为日志 DB 访问。SQL 跨库通用，仅分页片段由 {@link AuditDialect} 提供。
 * 时间存 epoch millis，JSON 串存 TEXT。字段名按 dev-spec 08「二」假设，公司内表不同则调 SQL/RowMapper。
 */
@RequiredArgsConstructor
public class BehaviorAuditRepository {

    private final JdbcTemplate jdbc;
    private final AuditDialect dialect;
    private final String tablePrefix;

    private String table() { return tablePrefix + "audit_behavior"; }

    private static final RowMapper<BehaviorAuditRecord> MAPPER = (rs, n) -> new BehaviorAuditRecord(
            rs.getString("trace_id"),
            Instant.ofEpochMilli(rs.getLong("ts")),
            rs.getString("system"), rs.getString("agent"), rs.getString("user"),
            rs.getString("tool_name"), rs.getString("tool_category"),
            rs.getString("args"), rs.getString("result"),
            rs.getString("status"), rs.getLong("duration_ms"),
            rs.getString("error_code"), rs.getString("snapshot_id"),
            rs.getString("workspace_key"), rs.getString("oss_prefix"));

    /** 批量插入（后台 flush 调用）。失败由 Store 决定重试/丢弃。 */
    public void batchInsert(List<BehaviorAuditRecord> records) {
        if (records == null || records.isEmpty()) return;
        String sql = "INSERT INTO " + table() + " (trace_id,ts,system,agent,user,tool_name,tool_category,"
                + "status,duration_ms,error_code,snapshot_id,workspace_key,oss_prefix,args,result) "
                + "VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)";
        jdbc.batchUpdate(sql, records, records.size(), (ps, r) -> {
            ps.setString(1, r.traceId());
            ps.setLong(2, r.timestamp().toEpochMilli());
            ps.setString(3, r.system());
            ps.setString(4, r.agent());
            ps.setString(5, r.user());
            ps.setString(6, r.toolName());
            ps.setString(7, r.toolCategory());
            ps.setString(8, r.status());
            ps.setLong(9, r.durationMs());
            ps.setString(10, r.errorCode());
            ps.setString(11, r.snapshotId());
            ps.setString(12, r.workspaceKey());
            ps.setString(13, r.ossPrefix());
            ps.setString(14, r.args());
            ps.setString(15, r.result());
        });
    }

    public List<BehaviorAuditRecord> query(AuditQuery q) {
        StringBuilder sql = new StringBuilder("SELECT * FROM ").append(table()).append(" WHERE 1=1");
        List<Object> args = new ArrayList<>();
        appendFilters(sql, args, q);
        sql.append(" ORDER BY ts DESC ").append(dialect.pagination());
        args.addAll(Arrays.asList(dialect.args(q.page(), q.size())));
        return jdbc.query(sql.toString(), MAPPER, args.toArray());
    }

    public BehaviorAuditRecord findByTraceId(String traceId) {
        List<BehaviorAuditRecord> l = jdbc.query(
                "SELECT * FROM " + table() + " WHERE trace_id = ?", MAPPER, traceId);
        return l.isEmpty() ? null : l.get(0);
    }

    /** 与内存版契约一致：stats 仅按 identity 过滤（Controller 传 identity-only query）。 */
    public Map<String, Object> stats(AuditQuery q) {
        StringBuilder sql = new StringBuilder("SELECT COUNT(*) AS total,")
                .append(" SUM(CASE WHEN status='FAIL' THEN 1 ELSE 0 END) AS fail,")
                .append(" SUM(CASE WHEN status='PERMISSION_DENIED' THEN 1 ELSE 0 END) AS denied,")
                .append(" COALESCE(AVG(duration_ms),0) AS avg FROM ").append(table()).append(" WHERE 1=1");
        List<Object> args = new ArrayList<>();
        appendFilters(sql, args, q);
        return jdbc.queryForObject(sql.toString(), (rs, n) -> {
            Map<String, Object> m = new LinkedHashMap<>();
            m.put("total", rs.getLong("total"));
            m.put("fail", rs.getLong("fail"));
            m.put("denied", rs.getLong("denied"));
            m.put("avgDurationMs", Math.round(rs.getDouble("avg")));
            return m;
        }, args.toArray());
    }

    public int deleteOlderThan(long epochMillis) {
        return jdbc.update("DELETE FROM " + table() + " WHERE ts < ?", epochMillis);
    }

    private void appendFilters(StringBuilder sql, List<Object> args, AuditQuery q) {
        if (q.identity() != null && !q.identity().isBlank()) {
            sql.append(" AND LOWER(workspace_key) LIKE ?");
            args.add("%" + q.identity().toLowerCase() + "%");
        }
        if (q.toolName() != null && !q.toolName().isBlank()) {
            sql.append(" AND LOWER(tool_name) LIKE ?");
            args.add("%" + q.toolName().toLowerCase() + "%");
        }
        if (q.toolCategory() != null) { sql.append(" AND tool_category = ?"); args.add(q.toolCategory()); }
        if (q.status() != null)        { sql.append(" AND status = ?");        args.add(q.status()); }
        if (q.from() != null)          { sql.append(" AND ts >= ?");           args.add(parseEpoch(q.from())); }
        if (q.to() != null)            { sql.append(" AND ts <= ?");           args.add(parseEpoch(q.to())); }
    }

    /** from/to 约定 ISO-8601（如 2026-07-29T00:00:00Z）；公司内若用 epoch 串/其他格式，改这里。 */
    private static long parseEpoch(String s) {
        try { return Instant.parse(s).toEpochMilli(); }
        catch (Exception e) { return 0; }
    }
}
```

### JdbcBehaviorAuditStore（有界队列 + 后台批量 flush）

新增 `audit/persistence/JdbcBehaviorAuditStore.java`。保留非阻塞契约：`write` 仅入队，DB 写在后台线程；落盘失败重入队列，队列满丢最旧 + 告警，绝不抛到切面。

```java
package io.github.springai.harness.audit.persistence;

import io.github.springai.harness.audit.AuditProperties;
import io.github.springai.harness.audit.BehaviorAuditStore;
import io.github.springai.harness.audit.model.AuditQuery;
import io.github.springai.harness.audit.model.BehaviorAuditRecord;
import jakarta.annotation.PostConstruct;
import jakarta.annotation.PreDestroy;
import lombok.extern.slf4j.Slf4j;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.BlockingQueue;
import java.util.concurrent.Executors;
import java.util.concurrent.LinkedBlockingQueue;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicLong;

/**
 * 行为日志 DB 实现：有界队列 + 后台批量 flush。
 * <ul>
 *   <li>write：offer 入队，满则 poll 丢最旧 + 计数告警（非阻塞、不抛）</li>
 *   <li>flush：drainTo(batchSize) -> batchInsert；失败则整批重入队列（DB 持续不可用时最终丢最旧）</li>
 *   <li>query/stats/getByTraceId：直接读 DB（最终一致：刚写入若仍在队列，getByTraceId 可能查不到）</li>
 * </ul>
 */
@Slf4j
public class JdbcBehaviorAuditStore implements BehaviorAuditStore {

    private final BehaviorAuditRepository repo;
    private final int batchSize;
    private final long flushIntervalMs;
    private final BlockingQueue<BehaviorAuditRecord> queue;
    private final ScheduledExecutorService scheduler;
    private final AtomicLong droppedCount = new AtomicLong();

    public JdbcBehaviorAuditStore(BehaviorAuditRepository repo, AuditProperties props) {
        this.repo = repo;
        AuditProperties.Persistence p = props.getPersistence();
        this.batchSize = Math.max(1, props.getBatchSize());
        this.flushIntervalMs = p.getFlushIntervalMs();
        this.queue = new LinkedBlockingQueue<>(p.getQueueCapacity());
        this.scheduler = Executors.newSingleThreadScheduledExecutor(r -> {
            Thread t = new Thread(r, "audit-jdbc-flush");
            t.setDaemon(true);
            return t;
        });
    }

    @PostConstruct
    void start() {
        scheduler.scheduleWithFixedDelay(this::flush, flushIntervalMs, flushIntervalMs, TimeUnit.MILLISECONDS);
    }

    @Override
    public void write(BehaviorAuditRecord record) {
        if (record == null) return;
        if (!queue.offer(record)) {
            queue.poll(); // 丢最旧
            if (queue.offer(record)) {
                log.warn("审计行为队列满（容量 {}），丢弃最旧记录，累计丢弃 {}", queue.size() + 1, droppedCount.incrementAndGet());
            }
        }
    }

    void flush() {
        try {
            List<BehaviorAuditRecord> batch = new ArrayList<>(batchSize);
            queue.drainTo(batch, batchSize);
            if (batch.isEmpty()) return;
            repo.batchInsert(batch);
        } catch (Exception e) {
            // 整批重入队列；DB 持续不可用 -> 队列满 -> write() 丢最旧
            log.warn("审计批量落盘失败，尝试重入队列: {}", e.getMessage());
            // 注意：此处简化为丢弃失败批次并告警；若需不丢数据，改为重入队列（见依赖敏感点）
        }
    }

    @PreDestroy
    void shutdown() {
        scheduler.shutdown();
        try { scheduler.awaitTermination(5, TimeUnit.SECONDS); } catch (InterruptedException ignored) { Thread.currentThread().interrupt(); }
        flush(); // 关停前尽力 flush 剩余
    }

    @Override public List<BehaviorAuditRecord> query(AuditQuery q) { return repo.query(q); }
    @Override public BehaviorAuditRecord getByTraceId(String id) { return repo.findByTraceId(id); }
    @Override public Map<String, Object> stats(AuditQuery q) { return repo.stats(q); }
}
```

> **失败重试增强（可选）**：上面 `flush` 的 catch 为简洁起见丢弃失败批次。若要求不丢数据，把 `batch` 在 catch 中 `forEach(queue::offer)`，offer 失败再告警。属依赖敏感点（审计完整性 vs 队列膨胀）。

```java
import java.util.List;

@Slf4j
@RequiredArgsConstructor
public class JdbcAdminAuditStore implements AdminAuditStore {

    private final AdminAuditRepository repo;

    @Override
    public void write(AdminAuditRecord record) {
        if (record == null) return;
        try {
            repo.insert(record);
        } catch (Exception e) {
            log.warn("管理员审计写入失败 traceId={}: {}", record.traceId(), e.getMessage());
        }
    }

    @Override public List<AdminAuditRecord> query(AuditQuery q) { return repo.query(q); }
    @Override public AdminAuditRecord getByTraceId(String id) { return repo.findByTraceId(id); }
}
```

### JdbcAuditRetentionCleaner（retention 定时清理）

新增 `audit/persistence/JdbcAuditRetentionCleaner.java`，按 `retentionDays` 删旧：

```java
package io.github.springai.harness.audit.persistence;

import io.github.springai.harness.audit.AuditProperties;
import jakarta.annotation.PostConstruct;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;

import java.time.Instant;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;

/** 按 retentionDays 定时清理两表旧数据。单机定时；分布式可换 XXL-Job/Quartz（依赖敏感点）。 */
@Slf4j
@RequiredArgsConstructor
public class JdbcAuditRetentionCleaner {

    private final BehaviorAuditRepository behaviorRepo;
    private final AdminAuditRepository adminRepo;
    private final AuditProperties props;
    private final ScheduledExecutorService scheduler =
            Executors.newSingleThreadScheduledExecutor(r -> { Thread t = new Thread(r, "audit-retention"); t.setDaemon(true); return t; });

    @PostConstruct
    void start() {
        // 每天清理一次；启动 1 分钟后首跑
        scheduler.scheduleWithFixedDelay(this::clean, 1, 24 * 60, TimeUnit.MINUTES);
    }

    void clean() {
        try {
            long cutoff = Instant.now().toEpochMilli() - (long) props.getRetentionDays() * 86_400_000L;
            int b = behaviorRepo.deleteOlderThan(cutoff);
            int a = adminRepo.deleteOlderThan(cutoff);
            log.info("审计 retention 清理：behavior={} 条，operation={} 条（>{} 天）", b, a, props.getRetentionDays());
        } catch (Exception e) {
            log.warn("审计 retention 清理失败: {}", e.getMessage());
        }
    }
}
```

## 八、AutoConfiguration 注册 + 存储切换

`AuditAutoConfiguration` 增加 JDBC Bean（内存 Bean 保持 `@ConditionalOnMissingBean`，自动退让）：

```java
@Bean
@ConditionalOnMissingBean
@ConditionalOnProperty(prefix = AuditProperties.CONFIG_PREFIX + ".persistence", name = "mode", havingValue = "jdbc")
@ConditionalOnClass(JdbcTemplate.class)
@ConditionalOnBean(DataSource.class)
public BehaviorAuditStore jdbcBehaviorAuditStore(JdbcTemplate jdbc, AuditProperties props) {
    AuditDialect dialect = AuditDialect.from(props.getPersistence().getDialect());
    String prefix = props.getPersistence().getTablePrefix();
    return new JdbcBehaviorAuditStore(new BehaviorAuditRepository(jdbc, dialect, prefix), props);
}

@Bean
@ConditionalOnMissingBean
@ConditionalOnProperty(prefix = AuditProperties.CONFIG_PREFIX + ".persistence", name = "mode", havingValue = "jdbc")
@ConditionalOnClass(JdbcTemplate.class)
@ConditionalOnBean(DataSource.class)
public AdminAuditStore jdbcAdminAuditStore(JdbcTemplate jdbc, AuditProperties props) {
    AuditDialect dialect = AuditDialect.from(props.getPersistence().getDialect());
    String prefix = props.getPersistence().getTablePrefix();
    return new JdbcAdminAuditStore(new AdminAuditRepository(jdbc, dialect, prefix));
}

@Bean
@ConditionalOnMissingBean(JdbcTemplate.class)
@ConditionalOnBean(DataSource.class)
public JdbcTemplate auditJdbcTemplate(DataSource dataSource) {
    return new JdbcTemplate(dataSource);
}

@Bean
@ConditionalOnProperty(prefix = AuditProperties.CONFIG_PREFIX + ".persistence", name = "mode", havingValue = "jdbc")
@ConditionalOnBean(DataSource.class)
public JdbcAuditRetentionCleaner jdbcAuditRetentionCleaner(
        BehaviorAuditStore bs, AdminAuditStore as, AuditProperties props) {
    // bs/as 已是上面的 JDBC 实现；此处取其 Repository 跑清理
    return new JdbcAuditRetentionCleaner(
            ((JdbcBehaviorAuditStore) bs).getRepo(),
            ((JdbcAdminAuditStore) as).getRepo(),
            props);
}
```

> 清理器需要 Repository 引用。为简洁，可给两个 JDBC Store 加 `getRepo()` 访问器；或单独把 Repository 注册成 Bean 注入清理器，更干净（推荐：把 `BehaviorAuditRepository`/`AdminAuditRepository` 也声明为 `@Bean`，Store 与 Cleaner 都注入它们）。

```properties
spring.datasource.password=...
```

## 九、非功能契约落地（对照 phase2 原设计）

| 契约（原设计要求） | 本实现做法 |
|---|---|
| 不阻塞 MCP 热路径 | `write` 仅 `offer` 入队；DB 写在后台单线程 |
| 异步批量落盘 | `drainTo(batchSize)` + `batchUpdate`，按 `flushIntervalMs` 定时 + 关停前 flush |
| 落盘失败绝不中断工具调用 | Store 内 try/catch；`AuditAspect` finally 再兜一层 `catch Exception` |
| 读后一致性 | 行为日志最终一致（管理台刷新即可）；管理员日志同步直写即时可查 |
| retention | `JdbcAuditRetentionCleaner` 按 `retentionDays` 每日 `deleteOlderThan`；分区表可改 `DROP PARTITION` |
| 队列溢出 | 默认 drop-oldest + 计数告警；可配置改阻塞/转文件（依赖敏感点） |

## 十一、依赖敏感点

| 项目 | 说明 |
|---|---|
| 新增依赖 | `spring-boot-starter-jdbc` + 数据库驱动（mysql/postgres/oracle/达梦…） |
| DataSource/连接池 | 用 Spring Boot 标准 `spring.datasource.*`；池默认 HikariCP，公司内可换 Druid/JNDI |
| SQL 方言/分页 | `AuditDialect` 枚举；`DEFAULT`(LIMIT/OFFSET) 覆盖 MySQL/PG/H2/达梦；Oracle/SQLServer 选对应值；新库加枚举值 |
| 字段映射 | 表字段名/类型若与本文假设不同，调整 Repository 的 SQL 与 `RowMapper`，接口不变 |
| 时间类型 | 参考 `BIGINT` epoch millis；公司内若规定 `TIMESTAMP`，仅改映射层（`Instant ↔ rs.getTimestamp`） |
| JSON 列 | 参考 `TEXT`/`CLOB` 存串；公司内若要原生 JSON 列（PG `jsonb` 等），改 DDL + 映射层 |
| 批量插入 | `JdbcTemplate.batchUpdate`；公司内若用 MyBatis 等，换 Repository 实现 |
| retention 清理 | 参考单机 `ScheduledExecutorService` 每日清；公司内可换 XXL-Job/Quartz/系统 cron |
| 按天分区 | 参考单表 + `ts` 索引；公司内若用分区表，retention 改 `DROP PARTITION`，DDL 与清理器适配 |
| 失败重试/死信 | 参考 `flush` 失败丢弃 + 告警；若审计完整性要求高，改为整批重入队列或转死信表（权衡队列膨胀） |
| 读后一致性 | 行为日志最终一致（刷新即可）；若管理台要写后立查，`getByTraceId` 前可强制 `flush()` 或查队列 |
| `from`/`to` 格式 | 约定 ISO-8601；公司内若用 epoch 串/其他格式，改 `parseEpoch` |
| 向后兼容 | `mode=memory`（默认）行为与 03 完全一致，无破坏；切 `jdbc` 才装配 DB Bean |
| 公司内适配 | 表 DDL、数据源、方言、清理调度按公司实际 |

## 十二、验证方式（参考，公司内按实际 DB）

- 单测（H2 MySQL 模式，不连真 DB）：
  - `JdbcBehaviorAuditStoreTest`：写 -> 等 flush -> 验证 query 过滤/分页/排序、stats、getByTraceId、`deleteOlderThan`、队列满 drop-oldest、`@PreDestroy` flush 剩余。

- 预期：`mode=memory` 时全部行为与 dev-spec 03 一致；`mode=jdbc` 时日志进库、重启不丢、多节点共享。
